# Agentic AI Library Feedback

This repository is the public place for reporting issues, suggesting improvements, and proposing new resources for Agentic AI Library.

Agentic AI Library is a public resource hub for Agentic AI topics, including organizational adoption, agentic engineering, architectures, evaluation, safety, and related domains.

Website: https://agenticlibrary.net

## What this repository is for

Use this repository to:

- Report bugs on the public website
- Suggest new features or UX improvements
- Suggest new resources, terms, or categories
- Report broken links or inaccurate content
- Suggest improvements to public-facing documentation

## What this repository is not for

Do not use this repository to request:

- Access to the private source code
- Internal implementation details
- Deployment details
- Private datasets or unpublished resource lists
- Security testing without permission
- Support for unrelated tools, frameworks, or projects

## Before opening an issue

Please check existing issues first to avoid duplicates.

When opening a new issue, use the most relevant template:

- Bug Report
- Feature Request
- Resource Suggestion
- Content Correction

## Disclosure note

Please do not include sensitive information in public issues. This includes passwords, tokens, private URLs, personal data, unpublished business information, or security vulnerability details.

For security concerns, follow the instructions in SECURITY.md.

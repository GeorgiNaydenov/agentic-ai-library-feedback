# Feature Request Guidelines

Use feature requests for public-facing improvements to Agentic AI Library.

## Strong feature requests include

- The problem or user need
- The proposed improvement
- The affected area of the website
- Why the improvement would be valuable
- Optional alternatives or simpler versions

## Good examples

- Improve filtering for large categories
- Add clearer glossary navigation
- Add a better way to suggest resources
- Improve mobile layout for resource cards
- Add visual discovery for major library domains

## Avoid

- Requests for private implementation details
- Requests for source code access
- Requests based only on internal technical assumptions
- Broad ideas without a clear user benefit

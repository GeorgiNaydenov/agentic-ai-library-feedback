# Resource Suggestion Guidelines

Use resource suggestions to propose new resources, tools, papers, frameworks, courses, or glossary terms for Agentic AI Library.

## Include

- Resource title
- Official URL
- Author, organization, or publisher
- Resource type
- Suggested category or domain
- Why it should be included

## Preferred sources

- Official documentation
- Publisher pages
- Research paper pages
- Official GitHub repositories
- Maintainer websites
- Public course or guide pages

## Quality signals

A strong resource is:

- Relevant to Agentic AI
- Publicly accessible
- Credible
- Useful to practitioners, researchers, builders, or decision-makers
- Specific enough to be categorized

## Avoid

- Duplicate resources
- Promotional links without clear value
- Unofficial mirrors when an official source exists
- Links that require private access
- Large copied text from copyrighted sources

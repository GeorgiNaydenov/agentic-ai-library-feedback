# Privacy and Disclosure

This repository is public. Anything posted in issues or comments may be visible to everyone.

## Do not post

- Passwords
- API keys
- Access tokens
- Private URLs
- Personal data
- Private business information
- Internal documents
- Security exploit details
- Confidential screenshots

## Safe public issue content

It is usually safe to share:

- Public website URLs
- Browser and device type
- Non-sensitive screenshots
- Broken public links
- Suggested public resources
- Publicly available source links

## Security concerns

Do not open public GitHub Issues for security concerns. Follow SECURITY.md instead.

# Code of Conduct

This repository is intended to keep feedback constructive, respectful, and useful.

## Expected behavior

- Be respectful and clear.
- Stay on topic.
- Provide enough context for issues to be actionable.
- Assume good intent when discussing suggestions or corrections.

## Unacceptable behavior

- Harassment, insults, or personal attacks
- Spam or promotional posts unrelated to Agentic AI Library
- Posting private information about others
- Posting secrets, credentials, or security exploit details publicly
- Repeated low-effort or duplicate issues

## Moderation

Issues or comments may be edited, hidden, locked, or closed if they are off-topic, unsafe, abusive, spammy, or not actionable.

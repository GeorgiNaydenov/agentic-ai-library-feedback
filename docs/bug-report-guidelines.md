# Bug Report Guidelines

Use bug reports for problems with the public Agentic AI Library website.

## Include

- Page or section affected
- What happened
- What you expected
- Steps to reproduce, if possible
- Browser and device details, if relevant
- Screenshot or screen recording, if useful

## Examples of useful bug reports

- Search does not return expected results
- A filter count looks incorrect
- A resource link is broken
- A page layout breaks on mobile
- A visual element overlaps another element

## Avoid

- Posting private information
- Posting security exploit details publicly
- Including unrelated technical assumptions

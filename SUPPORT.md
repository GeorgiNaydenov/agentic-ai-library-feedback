# Support

This repository is for public feedback about Agentic AI Library.

## Use GitHub Issues for

- Website bugs
- Broken links
- Missing resources
- Feature suggestions
- Content corrections
- Category or navigation feedback

## Do not use GitHub Issues for

- Private support requests
- Security vulnerabilities
- Requests for private source code
- Deployment questions
- Internal implementation questions

## Security reports

Do not open public issues for security concerns.

Use SECURITY.md for the correct reporting process.

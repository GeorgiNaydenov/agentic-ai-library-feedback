# Security Policy

Do not report security vulnerabilities through public GitHub Issues.

## How to report

Use GitHub's private security advisory feature:

[Report a vulnerability privately](https://github.com/GeorgiNaydenov/agentic-ai-library-feedback/security/advisories/new)

This keeps the report confidential until the issue has been reviewed and addressed.

---

## What counts as a security concern

Examples include:

- Exposed credentials or tokens
- Authentication or authorization problems
- Private data visible to unauthorized users
- Injection vulnerabilities
- Cross-site scripting
- Suspicious public behavior that could harm users

---

## What to include in your report

- A clear description of the concern
- The affected page or public URL
- Steps to reproduce, if safe to share privately
- Screenshots, if useful

---

## Public disclosure

Please do not publicly disclose security issues before they have been reviewed and addressed.

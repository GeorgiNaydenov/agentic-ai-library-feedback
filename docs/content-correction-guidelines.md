# Content Correction Guidelines

Use content corrections to report inaccurate, outdated, duplicated, or broken content on the public Agentic AI Library website.

## Include

- The page, section, or entry that needs correcting
- What currently appears (copy the text or describe it)
- What it should say or link to instead
- A reliable source or evidence, if available
- A brief explanation of why the correction matters

## Correction types

- Broken link — a resource URL no longer works
- Outdated content — information that was once accurate but is no longer current
- Duplicate resource — the same resource appears more than once
- Wrong category — a resource is placed in an incorrect domain or category
- Typo or wording — a spelling mistake or unclear phrasing
- Incorrect description — a description that misrepresents the resource or term

## Avoid

- Corrections based on personal preference rather than factual accuracy
- Posting private information
- Suggesting corrections to content that is not publicly visible on the website

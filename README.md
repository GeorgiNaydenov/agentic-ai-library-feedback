# Agentic AI Library — Public Feedback

This is the public home for feedback, bug reports, and resource suggestions for [Agentic AI Library](https://agenticlibrary.net).

Agentic AI Library is a curated resource hub for Agentic AI topics, including organizational adoption, agentic engineering, architectures, evaluation, safety, and related domains.

---

## Choose the right issue type

| I want to... | Issue type |
|---|---|
| Report a bug on the website | Bug Report |
| Suggest a new feature or UX improvement | Feature Request |
| Suggest a new resource, paper, tool, or guide | Resource Suggestion |
| Correct inaccurate, outdated, or broken content | Content Correction |

[Open a new issue](../../issues/new/choose) to get started. Each type has a guided form.

---

## What this repository is for

- Reporting bugs on the public website
- Suggesting new features or public user experience improvements
- Suggesting new resources, terms, or categories
- Reporting broken links or inaccurate content

## What this repository is not for

- Requests for private source code or internal implementation details
- Deployment or hosting questions
- Private datasets or unpublished content
- Security vulnerabilities (see below)
- Support for unrelated tools, frameworks, or projects

---

## Security concerns

Do not open a public issue for security concerns.

Use GitHub's private security advisory to report security issues: [Report a vulnerability](../../security/advisories/new).

See [SECURITY.md](SECURITY.md) for more detail.

---

## Before opening an issue

1. Check [existing issues](../../issues) to avoid duplicates.
2. Choose the correct template when opening a new issue.
3. Include only information that is safe to share publicly.

See [CONTRIBUTING.md](CONTRIBUTING.md) for full guidance.

---

## What to expect

Issues are reviewed manually. A response is not guaranteed or timely for all issues. Valid issues may be labeled, clarified, accepted, deferred, closed as duplicate, or closed as not planned.

Opening an issue does not guarantee implementation.

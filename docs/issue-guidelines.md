# Issue Guidelines

Use GitHub Issues to report public-facing feedback about Agentic AI Library.

## Good issues are

- Specific
- Clear
- Actionable
- Focused on one topic
- Supported with examples, screenshots, or source links when useful

## Before opening an issue

1. Check if a similar issue already exists.
2. Choose the correct issue template.
3. Include only information that is safe to share publicly.

## Do not include

- Passwords
- Tokens
- Private URLs
- Personal data
- Internal company information
- Security exploit details
- Assumptions about private implementation details

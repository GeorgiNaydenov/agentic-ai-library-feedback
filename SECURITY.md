# Security Policy

Please do not report security vulnerabilities through public GitHub Issues.

## What counts as a security concern

Examples include:

- Exposed secrets or credentials
- Authentication or authorization concerns
- Private data exposure
- Injection vulnerabilities
- Cross-site scripting
- Suspicious public behavior that could affect users

## What to include in a private report

Please include:

- A clear description of the concern
- The affected page or public URL
- Steps to reproduce, if safe to share privately
- Screenshots, if useful
- Your contact details, if you want follow-up

## Public disclosure

Please do not publicly disclose security issues before they have been reviewed and addressed.

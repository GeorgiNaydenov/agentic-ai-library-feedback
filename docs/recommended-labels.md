# Recommended GitHub Labels

Create these labels in the public feedback repository:

- bug
- feature-request
- resource-suggestion
- content-correction
- needs-triage
- needs-review
- accepted
- duplicate
- not-planned
- question
- good-first-issue
- accessibility
- mobile
- performance
- search
- filters
- visualization
- glossary
- documentation

Note: Labels referenced in issue forms should already exist in the repository if you want GitHub to apply them automatically.
